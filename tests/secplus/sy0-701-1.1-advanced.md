## Axis discipline

### Q1
A security officer is **posted statically** at a building entrance as part of the site's permanent protective arrangements. Which category and type pair is correct?

- A. Operational and Deterrent
- B. Physical and Preventive
- C. Operational and Preventive
- D. Physical and Deterrent

Answer: D
Explain: The source lists "Security guards" among the **Physical** examples, which
fixes the category, and "Security guards at entrances" among the **Deterrent**
examples, which fixes the type. Note how narrow this is: change the stem to a
scheduled patrol and the category becomes Operational, because the source lists
"Security guard patrols" there instead. The same personnel classify differently
depending on whether the stem describes the protective arrangement or the
activity being performed.

### Q2
Which statement about an Acceptable Use Policy is **FALSE**?

- A. Its category is Managerial, because management drafts and approves it
- B. Its type is Directive, because it instructs people what they must do
- C. Its category is Directive, because it directs employee behaviour
- D. It can carry both a category label and a type label simultaneously

Answer: C
Explain: Directive is a **type**, never a category. The four categories are
Technical, Managerial, Operational and Physical, and Directive is not among them.
An AUP is Managerial by category and Directive by type, which is why option D is
true rather than false. Candidates who have learned that "an AUP is directive"
without learning which axis that word sits on will pick A or B and miss that C is
the impossible claim.

### Q3
Which of the following is **not a valid pairing**, because one of its two terms is on the wrong axis?

- A. Technical and Preventive
- B. Managerial and Directive
- C. Deterrent and Physical
- D. Operational and Detective

Answer: C
Explain: A valid pairing is one category plus one type. Deterrent is a type and
Physical is a category, so "Deterrent and Physical" names a type first and a
category second, reversing the axes. The other three each name a genuine category
followed by a genuine type. Read pairings in order; a reversal is the easiest
error to overlook because both words are individually correct.

### Q4
A team applies the identical vendor patch in two situations: (i) during routine monthly maintenance on a system that has never been attacked, and (ii) during incident response on a system confirmed to have been exploited. Which classification is correct?

- A. (i) is preventive and (ii) is corrective
- B. Both are corrective, because patching always remediates a weakness
- C. Both are preventive, because patching always closes a vulnerability
- D. (i) is corrective and (ii) is preventive

Answer: A
Explain: The same technical action carries a different type depending on when it
occurs relative to the incident. Applied before any compromise it stops an
incident from happening, which is preventive. Applied after confirmed
exploitation it repairs the situation, which is corrective, and the source lists
"Patching an exploited vulnerability" among the Corrective examples. Options B and
C are each half right, which is what makes them tempting: they generalise one
correct reading across both cases.

### Q5
Two organizations place a server on an isolated network segment behind strict firewall rules. Organization A does so because the server runs unpatchable software from a defunct vendor. Organization B does so as routine segmentation for a fully patched, healthy server. How are the two measures classified?

- A. Both are compensating, because both isolate a server
- B. Both are preventive, because both block unauthorized traffic
- C. A is compensating and B is preventive
- D. A is preventive and B is compensating

Answer: C
Explain: This is the sharpest test of what "compensating" means. The technical
measure is identical in both cases, so the classification cannot come from the
measure itself. A compensating control is defined by what it **substitutes for**:
Organization A cannot apply the preferred control, so isolation stands in for it
and the underlying weakness remains unresolved. Organization B has no such
constraint, so its segmentation simply blocks unauthorized activity and is
preventive. Classification here depends on circumstance, not on configuration.

### Q6
A single CCTV installation is mounted in plain view specifically so intruders notice it, its footage is recorded and reviewed after incidents, and the installation appears on the facilities asset register. Which set of classifications is correct?

- A. Deterrent type, Detective type, Physical category
- B. Deterrent category, Detective type, Physical type
- C. Preventive type, Detective type, Technical category
- D. Deterrent type, Corrective type, Physical category

Answer: A
Explain: CCTV legitimately carries three labels, and the source supports all
three: visible cameras appear under Deterrent, CCTV footage monitoring appears
under Detective, and CCTV cameras appear under the Physical examples. The trap is
assuming a control must have exactly one answer. It has one category and one type
per stated function, and a stem that describes several functions elicits several
labels. Option B reverses the axes on two of the three.

## Plan versus perform

### Q7
An HR standard requires background checks for all privileged roles. A recruiter subsequently runs a check on one named candidate. How are the requirement and the act classified?

- A. Both are managerial, because the standard governs both
- B. Both are operational, because people carry out both
- C. The requirement is managerial and running the check is operational
- D. The requirement is operational and running the check is managerial

Answer: C
Explain: The source lists "Background check requirements" among the Managerial
examples, because management decides what should happen. Running an individual
check is people performing the activity, which the Managerial-versus-Operational
contrast places under Operational. Note the limit of the source here: it names
only the requirement explicitly, and the classification of the act follows from
the plan-versus-perform rule rather than from its own listed example.

### Q8
The source lists change management among the Operational examples. An executive committee then drafts and approves the policy that mandates the change management process. That policy is BEST classified as:

- A. Operational, because change management is an operational control
- B. Managerial, because drafting and approving a policy is planning
- C. Technical, because change management is enforced through tooling
- D. Directive, because the policy tells staff what they must do

Answer: B
Explain: The activity and the policy mandating the activity sit in different
categories. Change management as practised is Operational, but the policy
requiring it is management deciding what should happen, which is Managerial.
Option A is the trap for anyone who memorised the example without the rule.
Option D is the subtler trap: the policy genuinely is Directive, but Directive is
a **type**, and the question asks for a category.

### Q9
Which of the following is classified as **Operational** rather than Physical, despite involving physical security resources?

- A. Scheduled security guard patrols
- B. Concrete bollards at the main entrance
- C. Security lighting around the perimeter
- D. Badge readers on restricted doors

Answer: A
Explain: Bollards, security lighting and badge readers are all listed Physical
examples, because each physically protects or restricts access to a place.
Security guard patrols are listed under Operational, because people are
performing a daily activity. The distinction is not whether the control is
tangible but whether the thing being classified is a protective fixture or a
performed activity.

### Q10
Which of the following is classified as **Physical**, despite being an electronic device?

- A. An intrusion detection system
- B. Multifactor authentication
- C. Antivirus software
- D. A badge reader on a server room door

Answer: D
Explain: Badge readers are listed among the Physical examples. Electronics do not
make a control Technical; what matters is that the badge reader exists to
restrict access to a **place**, which is the defining purpose of the Physical
category. IDS, MFA and antivirus are all listed Technical examples because each
enforces security through software against systems and accounts rather than
guarding a location. Reasoning from "it has a circuit board" rather than from the
category definition produces the wrong answer here.

## Type boundaries

### Q11
A login screen displays a banner stating that all activity is monitored and misuse will be prosecuted. The same system locks an account after five failed attempts. Which is correct?

- A. Both are deterrent, because both discourage misuse
- B. The banner is deterrent and the lockout is preventive
- C. The banner is preventive and the lockout is deterrent
- D. Both are preventive, because both protect the account

Answer: B
Explain: Two controls on one screen, with different types. The banner only
discourages an attempt and blocks nothing, which the source lists under Deterrent.
The lockout actually stops the attack from continuing, which makes it Preventive.
Apply the test from the Preventive-versus-Deterrent contrast: does it block the
action, or merely make an attacker think twice?

### Q12
In the phishing walkthrough, the SIEM identifies suspicious email activity and the SOC then removes the malicious email and cleans the infected endpoints. What are these two steps, in order?

- A. Preventive then corrective
- B. Detective then compensating
- C. Corrective then detective
- D. Detective then corrective

Answer: D
Explain: Identification is Detective, and removal plus cleanup repairs damage
after the event, which is Corrective. Order matters in this walkthrough: the same
six types appear in sequence, and misreading the order inverts the answer.
Option C is the exact inversion and is the most frequently chosen wrong answer on
sequencing items.

### Q13
Which of the following is **NOT** a corrective control?

- A. Restoring data from backups after ransomware
- B. Removing malware from infected systems
- C. Reinstalling a compromised system from a known-good image
- D. Isolating an unpatchable legacy system behind firewall rules

Answer: D
Explain: Options A, B and C are all listed Corrective examples, each repairing
damage after an incident. Isolating an unpatchable legacy system is the source's
own Compensating example: nothing is being repaired, and the vulnerability is
still present. The measure exists only because the preferred control cannot be
applied.

### Q14
Which of the following is **NOT** a detective control?

- A. Retained audit trails
- B. Security log monitoring
- C. SIEM alert monitoring
- D. An email gateway blocking a malicious attachment before delivery

Answer: D
Explain: Audit trails, log monitoring and SIEM alert monitoring are all listed
Detective examples, and each identifies or records activity without stopping it.
The email gateway blocks the attachment before delivery, which stops the incident
from happening and is therefore Preventive. The discriminator is whether the
control observes or intervenes.

### Q15
Staff are instructed in writing to store sensitive printed documents in locked drawers at the end of each shift. The drawers themselves have working locks. Which is correct?

- A. The instruction is physical and the lock is directive
- B. Both the instruction and the lock are physical
- C. The instruction is directive and the lock is preventive
- D. Both the instruction and the lock are directive

Answer: C
Explain: Two separate controls are described and they must be classified
separately. The written instruction is the source's own Directive example. The
lock is a physical mechanism that blocks access, which is Preventive by type. The
common error is to let the physical drawer absorb the classification of the
instruction, or the reverse, when in fact the stem contains two distinct controls.

## Multi-control synthesis

### Q16
An email security gateway, which normally blocks malicious attachments before delivery, suffers an outage. While it is down, the mail team imposes a temporary rule blocking all external attachments, and removes the rule once the gateway is restored. During the outage, that temporary rule was BEST classified as:

- A. Preventive, because it blocked attachments from reaching mailboxes
- B. Compensating, because it substituted for a preferred control that was unavailable
- C. Corrective, because it was a response to the gateway outage
- D. Directive, because it instructed the mail system how to behave

Answer: B
Explain: Option A is the strongest distractor and is factually true as far as it
goes, since the rule does block attachments. But the defining characteristic of a
compensating control is that it stands in for a preferred control that cannot be
used, and that is precisely the situation during the outage. Compare this with
item 5: the test for compensating is always what the measure replaces, not what
the measure does.

### Q17
Which control type does the source define explicitly in terms of acting **after** a security incident has occurred?

- A. Deterrent
- B. Compensating
- C. Corrective
- D. Directive

Answer: C
Explain: Corrective controls are defined as those "used to fix problems after a
security incident occurs". Deterrent and Directive both act before an incident,
by discouraging and by instructing respectively. Compensating is defined by
substitution rather than by timing, which is why it can look corrective without
being so; a compensating control is frequently put in place before any incident
at all.

### Q18
An auditor remarks that a particular control "performs rather than plans". Which category is being described?

- A. Operational
- B. Managerial
- C. Technical
- D. Physical

Answer: A
Explain: The memory aid runs: Managerial plans, Operational performs, Technical is
technology, Physical protects places. "Performs rather than plans" is therefore
Operational, and it explicitly excludes Managerial. This item rewards knowing the
aid in both directions rather than only recognising it when prompted.

### Q19
A SOC analyst follows a documented runbook, written and approved by management, to triage an alert raised by the organization's antivirus platform. Three controls are in play. Which mapping is correct?

- A. The runbook is managerial, the triage is operational, the antivirus is technical
- B. The runbook is operational, the triage is managerial, the antivirus is technical
- C. The runbook is managerial, the triage is technical, the antivirus is operational
- D. All three are operational, because the SOC performs all of them

Answer: A
Explain: Each element must be classified on its own terms. The runbook is a
management-authored document deciding what should happen, so Managerial. The
analyst performing the triage is people carrying out a daily activity, so
Operational. The antivirus platform enforces its control through software, so
Technical. Option D is the trap for anyone who classifies by who is involved
rather than by what each control is.

### Q20
A data centre maintains: bollards at the vehicle entrance, an intrusion detection system on the network, a published annual risk assessment, and nightly guard patrols. In that order, the categories are:

- A. Physical, Technical, Managerial, Operational
- B. Physical, Technical, Operational, Managerial
- C. Operational, Technical, Managerial, Physical
- D. Physical, Operational, Managerial, Technical

Answer: A
Explain: Bollards are Physical, an IDS is Technical, a risk assessment is the
headline Managerial example, and guard patrols are Operational. Option B inverts
only the last two, which is the Managerial-versus-Operational confusion in its
most compact form: the risk assessment plans while the patrol performs.

## Limits of the source

### Q21
The source lists risk assessment among the Managerial examples. Which statement about its control **type** is most defensible?

- A. It is definitively preventive, because it leads to controls being put in place
- B. It is definitively detective, because it discovers weaknesses
- C. The source assigns it a category but no type, so any type must be argued rather than recalled
- D. It is definitively directive, because it tells the organization what to address

Answer: C
Explain: This item tests whether you know the limits of your material. Risk
assessment appears in the category list and never in any of the six type lists,
so there is no recallable answer. A defensible case exists for preventive, since
it identifies risk so controls can be applied in advance, and for detective, since
it discovers weaknesses. Knowing that the source is silent is more valuable than
picking one and defending it as settled, because an exam question built on this
point will supply the context needed to decide.

### Q22
Why can security guards be classified as either Physical or Operational depending on the question?

- A. Because guards are simultaneously hardware and personnel
- B. Because managerial authority can override a control's category
- C. Because guards act as a compensating control for weak perimeters
- D. Because the source lists guards among Physical examples and guard patrols among Operational examples, so the stem's wording decides

Answer: D
Explain: This is a property of the material, not an inconsistency in it. A guard
considered as part of the protective estate is Physical; the scheduled patrol that
guard performs is Operational. Both appear in the source, in different lists. On
any question involving guards, locate the cue in the stem before answering, and
treat a stem that emphasises an activity as pointing to Operational.

### Q23
Multifactor authentication appears in the source under the Technical examples and again under the Preventive examples. What does this demonstrate?

- A. That MFA has been misclassified in one of the two lists
- B. That category and type are independent axes, and a single control carries one label from each
- C. That technical controls are always preventive
- D. That preventive controls are always technical

Answer: B
Explain: There is no contradiction. Every control has both a category, meaning
what it is made of, and a type, meaning what it does. MFA is Technical and
Preventive at once. Options C and D are over-generalisations drawn from a single
example, and each is disproved elsewhere in the same material: an IDS is
technical but detective, and a door lock is preventive but physical.

### Q24
Which single example **disproves** the claim that all technical controls are preventive?

- A. A firewall that blocks malicious traffic
- B. An intrusion detection system that identifies and records intrusions
- C. Multifactor authentication that blocks an account takeover
- D. An access control list that denies unauthorized access

Answer: B
Explain: A counterexample must be technical but **not** preventive. An IDS is
enforced by technology, so it is Technical, yet it identifies and records rather
than blocking, so it is Detective. Options A, C and D are all technical and
preventive, so each is consistent with the claim and disproves nothing. Disproof
questions require locating the single case that breaks the rule, not the cases
that illustrate it.

### Q25
A published policy, approved by executives, instructs employees to report suspicious emails. A candidate classifies this as "Operational". What is the most precise correction?

- A. The classification is correct, because employees carry out the reporting
- B. The category is Managerial and the type is Directive; Operational describes neither
- C. The category is Directive and the type is Managerial
- D. The category is Technical, because the reporting is submitted through a system

Answer: B
Explain: The thing being classified is the published policy, not the act of
reporting. The policy is Managerial by category, since management drafted and
approved it, and Directive by type, since it instructs people what to do.
Operational would describe employees actually reporting a message, which is a
different control. Option C reverses the axes, and option A classifies by who
eventually acts rather than by what the control is.
