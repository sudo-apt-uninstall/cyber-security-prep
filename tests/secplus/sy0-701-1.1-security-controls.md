## Foundational definitions

### Q1
Which of the following BEST defines a security control?

- A. Any measure used to protect an organization's systems, networks, data and information from security risks
- B. A hardware appliance deployed at the network perimeter to filter traffic
- C. A documented procedure that employees are contractually required to follow
- D. A software agent that detects and quarantines malicious code

Answer: A
Explain: A security control is *any* measure protecting systems, networks, data and
information from security risks. B and D name specific controls rather than the
definition, and C describes a procedure, which is only one form a control can take.

### Q2
CompTIA Security+ SY0-701 classifies security controls along two axes. Which pair is correct?

- A. Internal controls and external controls
- B. Logical controls and physical controls
- C. Control categories and control types
- D. Mandatory controls and discretionary controls

Answer: C
Explain: The two axes are **categories**, meaning what the control is made of, and
**types**, meaning what the control does. The other pairs are not the SY0-701
classification.

### Q3
A control **category** answers which question?

- A. What is the control made of?
- B. When does the control act during an incident?
- C. Who authorized the deployment of the control?
- D. What residual risk remains after the control is applied?

Answer: A
Explain: Category tells you what the control is made of. Option B describes a control
*type*, not a category.

### Q4
A control **type** answers which question?

- A. What is the control made of?
- B. Which regulatory framework mandates the control?
- C. What is the total cost of ownership of the control?
- D. What does the control do, or when does it act during a security incident?

Answer: D
Explain: Type tells you what the control does, or when it acts during an incident.
Option A is the definition of a category.

### Q5
How many control categories and how many control types are defined in this objective?

- A. Six categories and four types
- B. Four categories and six types
- C. Five categories and five types
- D. Four categories and four types

Answer: B
Explain: Four categories (Technical, Managerial, Operational, Physical) and six types
(Preventive, Deterrent, Detective, Corrective, Compensating, Directive).

### Q6
Which of the following is NOT a security control category?

- A. Preventive
- B. Managerial
- C. Operational
- D. Physical

Answer: A
Explain: Preventive is a *type*, not a category. Mixing the two axes is the single most
common error on this objective.

### Q7
Which of the following is NOT a security control type?

- A. Deterrent
- B. Compensating
- C. Directive
- D. Physical

Answer: D
Explain: Physical is a *category*, not a type. This is the mirror image of the previous
item, and the two are worth drilling together.

### Q8
An organization deploys multifactor authentication on all administrative accounts. Into which category does this control fall?

- A. Technical
- B. Managerial
- C. Operational
- D. Physical

Answer: A
Explain: MFA is enforced by technology, so the category is Technical. Note that MFA is
also a *preventive* type. Category and type are independent axes, and this item asked
only for the category.

### Q9
Full-disk encryption is applied to every corporate laptop. This is BEST categorized as which control category?

- A. Technical, because the protection is enforced by software
- B. Physical, because it protects the device
- C. Operational, because the help desk performs the installation
- D. Managerial, because an executive approved the project

Answer: A
Explain: Encryption is enforced by software, so the category is Technical. B is the trap:
the laptop is a physical object, but the control protecting it is software-enforced.
C and D describe who installed or approved it, which never determines the category.

### Q10
An access control list is configured on a router to deny traffic from an untrusted subnet. Which category applies?

- A. Operational
- B. Technical
- C. Managerial
- D. Directive

Answer: B
Explain: An ACL is a technology-enforced control, so Technical. Option D is not a
category at all.

## Category identification

### Q11
An organization conducts an annual enterprise risk assessment to identify and prioritize threats to its business units. Which control category does this activity represent?

- A. Managerial
- B. Operational
- C. Technical
- D. Detective

Answer: A
Explain: Risk assessment is the headline Managerial example, because it is planning and
risk decision-making. Option D is a type, not a category.

### Q12
Before onboarding a new cloud provider, a company applies a documented set of vendor selection criteria that the provider must satisfy. This is an example of which category?

- A. Technical
- B. Physical
- C. Operational
- D. Managerial

Answer: D
Explain: Vendor selection criteria are a listed Managerial example, since management sets
the standard the provider must meet.

### Q13
A company's hiring standard states that all candidates for privileged roles must clear a background check. The **requirement itself** is which category of control?

- A. Operational
- B. Technical
- C. Physical
- D. Managerial

Answer: D
Explain: Background check *requirements* are a listed Managerial example, because the
requirement is set by management. Running an individual check would be the operational
execution of it.

### Q14
The security team performs scheduled quarterly reviews of user entitlements and revokes dormant accounts. Which category BEST describes this work?

- A. Managerial
- B. Technical
- C. Operational
- D. Compensating

Answer: C
Explain: User access reviews are a listed Operational example, and here people are
performing the activity rather than deciding that it should happen.

### Q15
An organization maintains and follows a formal change management process for all production modifications. Which category applies?

- A. Operational
- B. Managerial
- C. Technical
- D. Physical

Answer: A
Explain: Change management is a listed Operational example.

### Q16
Uniformed officers walk a scheduled patrol route through a data centre campus each night. This **patrol activity** is BEST categorized as:

- A. Physical
- B. Managerial
- C. Deterrent
- D. Operational

Answer: D
Explain: Security guard *patrols* are a listed Operational example, because people are
performing a daily activity. Read the stem carefully here: the source lists "Security
guards" under Physical and "Security guard patrols" under Operational. A static posted
guard forming part of the protective estate is Physical, while the scheduled patrol they
perform is Operational. If you chose A, you were not wrong about guards in general, but
you missed the cue word.

### Q17
Concrete bollards are installed in front of the main entrance of a corporate headquarters. Which category applies?

- A. Physical
- B. Operational
- C. Technical
- D. Managerial

Answer: A
Explain: Bollards are a listed Physical example, because they physically restrict access
to a place.

### Q18
High-intensity security lighting is installed around the perimeter of a warehouse. Which category applies?

- A. Technical
- B. Operational
- C. Managerial
- D. Physical

Answer: D
Explain: Security lighting is a listed Physical example.

### Q19
Badge readers are fitted to every door on a restricted floor. Which category applies?

- A. Physical
- B. Technical
- C. Operational
- D. Managerial

Answer: A
Explain: Badge readers are a listed Physical example. They are electronic, but their
purpose is to restrict access to a place, which is what defines the Physical category.

### Q20
An organization documents a set of incident response procedures, and the SOC executes them during live events. The **execution** of those procedures is which category?

- A. Managerial
- B. Technical
- C. Operational
- D. Corrective

Answer: C
Explain: Executing incident response procedures is people performing the activity, so
Operational. Option D is a type, not a category.

### Q21
Executive management drafts, approves and publishes the corporate information security policy. Which category does the published policy represent?

- A. Operational
- B. Directive
- C. Technical
- D. Managerial

Answer: D
Explain: A published security policy is Managerial. Option B is the trap: Directive is a
*type*, and this item asked for the category. A policy is commonly both Managerial as a
category and Directive as a type.

### Q22
Management issues a policy mandating that every employee complete annual security awareness training. The **policy** is which category?

- A. Operational
- B. Technical
- C. Managerial
- D. Physical

Answer: C
Explain: Creating the policy is management deciding what should happen, so Managerial.

### Q23
Following that mandate, the security team schedules and delivers the training sessions to staff. The **delivery of the training** is which category?

- A. Managerial
- B. Directive
- C. Technical
- D. Operational

Answer: D
Explain: Delivering the training is people performing the activity, so Operational. This
item and the previous one form the classic paired trap: the same subject splits across two
categories depending on whether management is planning or staff are performing.

### Q24
An administrator maintains golden images and enforces standardized build settings across the server estate. This configuration management work is which category?

- A. Operational
- B. Technical
- C. Managerial
- D. Preventive

Answer: A
Explain: Configuration management is a listed Operational example. Option D is a type.

### Q25
Which statement MOST accurately distinguishes managerial controls from operational controls?

- A. Managerial controls are automated; operational controls are manual
- B. Managerial controls decide what should happen; operational controls make it happen
- C. Managerial controls apply to staff; operational controls apply to systems
- D. Managerial controls are preventive; operational controls are detective

Answer: B
Explain: The three contrasts are: creates the policy versus performs the activity, focuses
on planning versus focuses on execution, and decides what should happen versus makes it
happen. Option A is wrong because managerial controls are not automated. C and D invent
distinctions the objective does not make.

## Type identification

### Q26
A next-generation firewall drops inbound packets matching a known malicious signature before they reach the internal network. Which control type is this?

- A. Detective
- B. Preventive
- C. Deterrent
- D. Corrective

Answer: B
Explain: The firewall blocks the traffic before it succeeds, which is the definition of
Preventive.

### Q27
An access control list denies an unauthorized user's attempt to reach a file share. Which type applies?

- A. Deterrent
- B. Detective
- C. Preventive
- D. Directive

Answer: C
Explain: An ACL denying access blocks the action, so Preventive.

### Q28
A mechanical lock on a server room door physically stops an unauthorized person from entering. Which type applies?

- A. Deterrent
- B. Physical
- C. Compensating
- D. Preventive

Answer: D
Explain: A lock physically blocks entry, so the type is Preventive. Option B is the trap:
Physical is the category of a lock, not its type.

### Q29
Multifactor authentication blocks an attacker who has obtained a valid password but no second factor. Which type applies?

- A. Detective
- B. Preventive
- C. Corrective
- D. Compensating

Answer: B
Explain: MFA preventing unauthorized account access is a listed Preventive example.

### Q30
A sign reading "Beware of Dog" is posted on a perimeter fence. Which control type does the sign represent?

- A. Preventive
- B. Deterrent
- C. Directive
- D. Physical

Answer: B
Explain: This is the textbook Deterrent example. The sign discourages an attempt but
blocks nothing.

### Q31
A banner is displayed at logon stating that all activity is monitored and unauthorized use will be prosecuted. Which type applies?

- A. Directive
- B. Detective
- C. Deterrent
- D. Preventive

Answer: C
Explain: Login warning banners are a listed Deterrent example. They discourage the
attempt without preventing it.

### Q32
Dome cameras are mounted in plain view at every entrance specifically so that would-be intruders notice them. In this stated context, the cameras function MOST directly as which type?

- A. Deterrent
- B. Detective
- C. Preventive
- D. Corrective

Answer: A
Explain: The stem states the cameras are visible *so that intruders notice them*, and that
stated purpose is discouragement, so Deterrent. Option B is defensible for cameras in
general, which is exactly why the stem fixes the context. Always read for the purpose
given.

### Q33
An intrusion detection system identifies and records anomalous traffic traversing a monitored segment. Which type applies?

- A. Preventive
- B. Deterrent
- C. Detective
- D. Compensating

Answer: C
Explain: IDS identifies and records, so Detective. It does not block, which rules out
Preventive. An intrusion *prevention* system would be the preventive counterpart.

### Q34
An analyst reviews recorded CCTV footage after a reported theft to establish what occurred. In this context the footage review is which type?

- A. Deterrent
- B. Detective
- C. Corrective
- D. Preventive

Answer: B
Explain: Reviewing footage after the fact to establish what happened is Detective. CCTV
footage monitoring is a listed Detective example.

### Q35
Immutable audit trails are retained so that user actions can be reconstructed during an investigation. Which type applies?

- A. Detective
- B. Directive
- C. Preventive
- D. Corrective

Answer: A
Explain: Audit trails are a listed Detective example.

### Q36
A SIEM platform correlates log sources and raises alerts on suspicious patterns. Which type applies?

- A. Preventive
- B. Corrective
- C. Compensating
- D. Detective

Answer: D
Explain: SIEM alert monitoring is a listed Detective example.

### Q37
Following a ransomware event, an organization restores affected file shares from backup media. Which type applies?

- A. Preventive
- B. Corrective
- C. Compensating
- D. Detective

Answer: B
Explain: Restoring from backup repairs damage after the incident, so Corrective.

### Q38
After confirming that an internet-facing service was exploited, the team applies the vendor patch that closes the vulnerability. Which type BEST describes this action?

- A. Preventive
- B. Compensating
- C. Corrective
- D. Directive

Answer: C
Explain: The stem specifies the service was **already exploited**, so the patch is
remediation after the fact, which is Corrective. Option A is the trap: patching in the
abstract is preventive, but patching an exploited vulnerability during incident response
is corrective. Timing determines the type.

### Q39
An endpoint team removes malware from a set of infected workstations and returns them to service. Which type applies?

- A. Detective
- B. Corrective
- C. Preventive
- D. Deterrent

Answer: B
Explain: Malware removal is a listed Corrective example.

### Q40
A compromised host is rebuilt from a known-good image following an incident. Which type applies?

- A. Compensating
- B. Preventive
- C. Corrective
- D. Directive

Answer: C
Explain: Reinstalling compromised systems is a listed Corrective example.

### Q41
A legacy application contains a known vulnerability. The vendor has ended support and no patch exists, and the business cannot retire the system. Security places the host on an isolated network segment behind restrictive firewall rules. Which type do these measures represent?

- A. Preventive
- B. Corrective
- C. Compensating
- D. Detective

Answer: C
Explain: The preferred control, meaning patching or retiring the system, cannot be
implemented, so isolation and firewall rules substitute for it. That substitution is what
makes it Compensating.

### Q42
Which of the following BEST describes a compensating control?

- A. An alternative measure used when the original or preferred control cannot be implemented
- B. A control that stops an attack from succeeding
- C. A control that restores normal operation after an incident
- D. A control that records evidence of suspicious activity

Answer: A
Explain: B describes preventive, C describes corrective and D describes detective.

### Q43
Employees are required to sign an Acceptable Use Policy that states what they must and must not do with corporate assets. Which type applies?

- A. Managerial
- B. Preventive
- C. Deterrent
- D. Directive

Answer: D
Explain: An AUP instructs people what they must do, so Directive. Option A is the trap:
Managerial is its category, not its type.

### Q44
Printed instructions posted inside a restricted laboratory tell staff how to handle and store controlled media. Which type applies?

- A. Deterrent
- B. Preventive
- C. Directive
- D. Operational

Answer: C
Explain: Instructions displayed in restricted areas are a listed Directive example.

### Q45
Staff are instructed in writing to store sensitive printed documents in locked drawers at the end of each shift. The written instruction is which type?

- A. Physical
- B. Preventive
- C. Detective
- D. Directive

Answer: D
Explain: Instructions to store sensitive documents in locked drawers are a listed
Directive example. Option A is the trap: the drawer is physical, but the thing being
classified is the instruction.

## Applied scenarios and discriminators

### Q46
An organization installs a door lock and, separately, a warning sign on the same entrance. Which statement correctly explains the difference in control type?

- A. Both are preventive, because both protect the entrance
- B. The lock is deterrent because it warns; the sign is preventive because it blocks
- C. The lock is preventive because it blocks entry; the sign is deterrent because it discourages an attempt
- D. Both are deterrent, because neither guarantees the intruder is stopped

Answer: C
Explain: The lock blocks entry, making it preventive, while the sign only discourages the
attempt, making it deterrent. Option B inverts the two.

### Q47
A SOC analyst receives a Splunk alert for multiple failed login attempts against a finance server. The alert itself is which control type?

- A. Preventive
- B. Detective
- C. Corrective
- D. Deterrent

Answer: B
Explain: This is the source's own SOC example of a Detective control: the alert helps the
team detect suspicious activity.

### Q48
Continuing from the previous item, the team then resets the targeted account and patches the exposed service. These follow-on actions are which type?

- A. Detective
- B. Compensating
- C. Preventive
- D. Corrective

Answer: D
Explain: Resetting the account and patching the exposed service repairs the situation
after the event, so Corrective.

### Q49
During a phishing campaign, an email security gateway blocks a malicious attachment before delivery to any mailbox. Which category and type pair is correct?

- A. Operational and Detective
- B. Technical and Preventive
- C. Managerial and Directive
- D. Physical and Preventive

Answer: B
Explain: The gateway is software enforcing the control, making the category Technical, and
it blocks the attachment before delivery, making the type Preventive.

### Q50
In the same phishing response, employees are instructed to report any suspicious messages to the SOC. Which type does this instruction represent?

- A. Deterrent
- B. Detective
- C. Directive
- D. Corrective

Answer: C
Explain: Instructing employees to report suspicious emails is Directive, and it appears in
exactly that role in the phishing walkthrough.

### Q51
The gateway in the earlier item suffers an outage. While it is unavailable, the mail team imposes a temporary rule blocking all external attachments. This temporary measure is BEST classified as which type?

- A. Preventive
- B. Compensating
- C. Corrective
- D. Directive

Answer: B
Explain: The preferred control, the gateway, is unavailable, so the temporary rule stands
in for it. Option A is the trap: the rule does block attachments, but its defining
characteristic here is that it substitutes for an unavailable control.

### Q52
An intrusion detection system is deployed on a monitored segment. Which category and type pair is correct?

- A. Technical and Detective
- B. Operational and Detective
- C. Technical and Preventive
- D. Managerial and Detective

Answer: A
Explain: IDS is a Technical category control because technology enforces it, and a
Detective type because it identifies and records rather than blocks.

### Q53
A badge reader controls entry to a restricted server room. Which category and type pair is correct?

- A. Technical and Deterrent
- B. Physical and Detective
- C. Physical and Preventive
- D. Operational and Preventive

Answer: C
Explain: A badge reader is Physical because it restricts access to a place, and Preventive
because it blocks unauthorized entry.

### Q54
An Acceptable Use Policy is published by management and issued to all staff. Which category and type pair is correct?

- A. Operational and Directive
- B. Managerial and Directive
- C. Managerial and Preventive
- D. Directive and Managerial

Answer: B
Explain: An AUP is Managerial as a category and Directive as a type. Option D reverses the
axes and is invalid, because Directive is never a category and Managerial is never a type.

### Q55
Which of the following pairs a control with the WRONG type?

- A. Firewall blocking malicious traffic — Preventive
- B. Warning sign discouraging attackers — Deterrent
- C. Isolating an unpatchable legacy system — Preventive
- D. Malware removed from a system — Corrective

Answer: C
Explain: Isolating an unpatchable legacy system is Compensating, not Preventive, because
it substitutes for a patch that cannot be applied. The other three pairings are correct.

### Q56
Which single option correctly completes the standard memory aid for the four categories?

- A. Managerial = Performs, Operational = Plans, Technical = Protects places, Physical = Technology
- B. Managerial = Technology, Operational = Protects places, Technical = Plans, Physical = Performs
- C. Managerial = Protects places, Operational = Technology, Technical = Performs, Physical = Plans
- D. Managerial = Plans, Operational = Performs, Technical = Technology, Physical = Protects places

Answer: D
Explain: Managerial plans, Operational performs, Technical is technology, and Physical
protects places.

### Q57
A SOC analyst is asked which control category is engaged when investigating an alert generated by the organization's firewall and antivirus tooling. The BEST answer is:

- A. Operational, because an analyst performs the investigation
- B. Technical, because the alert originates from technology enforcing the control
- C. Managerial, because policy requires the investigation
- D. Physical, because the firewall is a hardware appliance

Answer: B
Explain: The category is determined by what enforces the control, not by who reacts to it.
Option A is the strongest distractor, since the analyst's triage work is genuinely
Operational, but the item asks about the control generating the alert.

### Q58
Security warning banners are deployed across the estate during a phishing response specifically to discourage unauthorized activity. Which type applies?

- A. Deterrent
- B. Directive
- C. Preventive
- D. Detective

Answer: A
Explain: The stem states the banners were deployed to discourage unauthorized activity,
which is the definition of Deterrent.

### Q59
An auditor asks why a particular measure was classified as compensating rather than preventive. Which justification is correct?

- A. The measure is cheaper than the preferred control
- B. The measure was approved by management rather than engineering
- C. The measure acts after the incident rather than before it
- D. The measure substitutes for a preferred control that cannot be implemented, and the underlying weakness remains unresolved

Answer: D
Explain: Cost and approval route are irrelevant to classification, and option C describes
corrective. What makes a control compensating is that it stands in for a preferred control
that cannot be implemented.

### Q60
An organization wants a single control that will discourage intruders, record their activity for later review, and be classified as a physical asset on the estate. Which deployment BEST satisfies all three requirements?

- A. A firewall with full logging enabled
- B. A visible CCTV installation whose footage is actively monitored and retained
- C. An Acceptable Use Policy distributed to all staff
- D. A documented incident response procedure

Answer: B
Explain: A visible CCTV installation satisfies all three: visible makes it deterrent,
monitored and retained makes it detective, and the installation itself is a Physical
asset. Option A is Technical, C is Managerial and Directive, and D is Operational.
